# 教学题库维护与验收

题库提供 50 道题的题面、样例、标签和 1,283 组确定性测试数据：简单 20 道、中等 22 道、困难 8 道。基础数学与模拟题用于入门，随后覆盖双指针、前缀和、哈希、贪心、背包、图论与进阶数据结构。保留原有 A+B 和“两数之和”两道同类入门题，避免破坏既有提交与课程关联。

题目由本项目编写，不依赖抓取第三方题库。参考程序仅用于维护者验收，不写入题目描述或公开接口。小数据答案由穷举、图传递闭包等朴素算法生成，再与独立参考程序交叉核对；大数据用例采用可直接核算答案的构造。

## 导入

需要 Python 3.10+，仅用标准库。在仓库根目录执行。服务启动前，旧数据库先按 README 备份并迁移结构。

```bash
# 离线检查，不连接服务
python3 tools/seed_demo_problems.py --dry-run
python3 -m unittest discover -s tools/tests -v

# 使用当前环境的管理员账号；不要将真实密码写入 Git
export BASE_URL=http://localhost:18080/api
export ADMIN_USER=preview_admin
read -rs -p '管理员密码: ' ADMIN_PASS; echo
export ADMIN_PASS
python3 tools/seed_demo_problems.py --report .tmp/bank-import-report.json
unset ADMIN_PASS
```

PowerShell 可用 `$env:BASE_URL`、`$env:ADMIN_USER`、`$env:ADMIN_PASS` 设置相同环境变量，再运行 `python tools/seed_demo_problems.py`。账号由现有平台注册和提权流程准备，脚本不会重置账号密码。

默认仅新增，按管理员可见的全部分页查重，包含下架题。新题先存为下架草稿，用例导入成功后才上架；失败的草稿可凭状态文件续跑。状态文件默认 `.tmp/problem-bank-import.json`，只记录环境地址和本次创建的题目 ID，不含密码或令牌。不同环境应使用不同 `--state` 路径。

原有题库需要补齐时，在备份后、暂停提交的维护窗口执行：

```bash
python3 tools/seed_demo_problems.py --enrich-existing --repair-known \
  --report .tmp/bank-enrichment-report.json
```

`--enrich-existing` 仅处理题面与清单完全一致的题：补空标签、追加缺失用例，保留题号、限制、语言、上下架状态与额外自定义用例。题面不同则跳过；发现同一输入存在未知的冲突答案则停止，保留现场。历史提交和判题结果不重写。

`--repair-known` 精确处理两处已确认的旧数据错误：二分查找中 `5 3 / 1 2 3 4 5` 的零基下标应为 `2`；数组求和中原来的单元素 `10^9` 超出题面 `|a_i| ≤ 10^4`，换为合法边界 `10000`。先追加正确用例，再删除明确匹配的错误用例。其他题面、用例不批量覆盖。

Nginx 允许最大 16 MiB 请求体，导入器按约 4 MiB 和最多 100 组拆批；单组过大的数据会拒绝导入。不要将 `sql/schema.sql` 重复导入现有库来代替结构迁移。

## 真实判题验收

先使用专门的普通学生账号。服务必须使用 `ENGINE_MODE=real`，并构建好五语言沙箱镜像；验收工具不会切换或绕过引擎模式和学生限流。

```bash
export BASE_URL=http://localhost:18080/api
export VERIFY_USER=bank_verifier
read -rs -p '验收学生密码: ' VERIFY_PASS; echo
export VERIFY_PASS
python3 tools/verify_problem_bank.py --report .tmp/bank-judge-report.json
unset VERIFY_PASS
```

每 11 秒提交一题，遵守每分钟 6 次限流；50 题提交约需 9 分钟，排队和执行时间另计。报告记录每道题的提交 ID、参考程序哈希、判题状态、逐例结果和资源用量，不记录令牌。单题复测可使用 `--title '二分查找'`，参数可重复。仅有 AC 状态但缺少完整用例结果、或标记为 mock 的提交不会计为验收通过。

区间和、差分、动态区间查询、并查集和 LCA 同时覆盖大数组及大量操作；另有十万顶点链/环、百万字符重复匹配、64 位逆序对计数等用例。题库不是完整竞赛测试集，后续新增题仍应加入反例、独立答案校验和真实判题验收。

## 配套页面修正

- 个人统计始终返回简单、中等、困难三行；未做过的难度也计入总题数。
- `solvedCount` 保留历史解题数，`availableSolvedCount` 只统计仍在架的已解题，用于当前题库覆盖率。
- 题库标签来自全部在架题，而非当前页；下架题元信息不进入公开概览。
- 横幅累计提交取全站统计；搜索及更改筛选时返回第一页。
